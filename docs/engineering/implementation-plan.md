# Implementation status

Source requirements: [product specification](../product/offline-music-player-spec.md). Visual reference: [prototype mapping](../design/prototype-mapping.md).

## Delivered implementation

- Native iOS 15-targeted Xcode app, branded SoundBunker with an app icon; no shipped demo/test audio.
- Library home, songs, albums/details, artists, genres, source/folder browsing, search, playlists/favorites, Settings, mini-player and full-screen Now Playing based on the supplied prototype.
- Core Data index, app-owned Documents scan, external folder bookmarks, file import, cancellation/progress, fingerprints, overlapping-root identities and unavailable-file preservation.
- Automatic scan on opening/foreground; persisted source disable switches and subfolder exclusions.
- Native audio engine, queues, play-next/add-to-queue, previous/next, shuffle/repeat, system media metadata/commands, interruption/route handling and silent restoration.
- Editable local playlists and local plain/LRC lyrics. Artwork thumbnails and bounded caches.
- Reproducible Release IPA plus outer ZIP workflow, saved in repository instructions.

## Remaining v1 work

- More complete per-format metadata extraction, including MP4 binary track/disc tags, year and synchronized embedded lyrics.
- Queue reorder/remove and restoration of pre-shuffle ordering.
- Folder reconnect/provider/cancellation/source-removal coverage on actual iOS; large-library fetch/search measurements and performance/accessibility QA on the iPod.
- Verified device codec matrix, background audio, Control Center, wired/Bluetooth controls and battery/memory evidence.
- iOS 15 XCTest execution with a supported Xcode/macOS setup.

No third-party decoder has been added. Artist-photo enrichment uses a small optional Wikimedia client. Features may be implemented without being physically verified; consult [testing](../testing/testing.md) for the distinction.

## Follow-up polish delivered

Pinned Now Playing control dock, cached rotated artwork surface tint, duplicate-safe manual playlist additions with checkmark feedback, current-song playlist picker, and keyboard-aware mini-player offset. Regression tests and Release compilation passed; compact native render inspected. Actual iPod keyboard/tint/performance QA is pending.

## 1.2.0 packaged implementation

Automatic ordered M3U/M3U8 imports and unresolved-entry display; selected File Provider folder support; GitHub links derived from origin; optional cached/attributed artist photos; compact followed lyrics; artist/album song-menu navigation; artwork next/previous swipes; native navigation/modal edge-back support. Foreground scans are throttled, browse groups cached, cache trimming moved off the UI thread, playback activation serialized off the main actor, and progress publication isolated from library consumers. See [feature QA](../testing/verification/feature-expansion-qa.md). Device interaction/performance certification remains pending.
