# Future optional enrichment

After the fully offline v1 is verified, consider explicitly user-triggered online metadata matching, missing-cover lookup and lyric lookup/download. Each would need an opt-in flow, source provenance and clear offline failure behavior.

Optional Wikimedia artist photos are implemented at the user’s explicit request in the packaged 1.2.0 release. Missing album-cover and lyric lookup remain unimplemented; no account or third-party SDK is required. The remaining offline phases are tracked in [the implementation plan](../engineering/implementation-plan.md), not deferred to this roadmap.
