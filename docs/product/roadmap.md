# Future optional enrichment

After the fully offline v1 is verified, consider explicitly user-triggered online metadata matching, missing-cover lookup and lyric lookup/download. Each would need an opt-in flow, source provenance and clear offline failure behavior.

No network layer, SDK, account or enrichment scaffold is implemented in v1. The remaining offline phases are tracked in [the implementation plan](../engineering/implementation-plan.md), not deferred to this roadmap.
