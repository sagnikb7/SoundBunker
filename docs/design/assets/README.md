# Cassette design assets

`retro-rainbow-cassette-original.png` is the exact 1254×1254 opaque PNG supplied by the designer through the user on 13 October 2026. It is preserved byte-for-byte, including its background, framing and rounded-square artwork.

`cassette-icon.png` is the current 1024×1024 production icon, identical to the app AppIcon asset and used by README. Both app and extension use the same 64×64 derived widget mark. Assets were resized using macOS sips; no recoloring, cropping, AI regeneration or redesign was applied. The previous Cassette production icon was replaced in all active asset locations.

The original pre-rebrand icon/renderer and `widget-selected-concept.png` remain historical user design references. They are not current branding and are not bundled as sample music or artwork. See [Cassette widgets and branding](../cassette-widgets.md).

The earlier `frosted-rainbow-cassette-original.png` remains only as the superseded designer source. Active asset catalogs, README and current widget captures use the latest retro artwork.
