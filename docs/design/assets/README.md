# Cassette design assets

`cassette-icon.png` is the current production Cassette icon, copied from the app’s AppIcon asset for repository documentation. The README uses this mark; the app and widget share the Cassette artwork in their asset catalogs.

The earlier icon/renderer and `widget-selected-concept.png` are preserved design-history references. They are not current branding and are not bundled as sample artwork or music. See [Cassette widgets and branding](../cassette-widgets.md) for the selected design, generation prompt and resource policy.
